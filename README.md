# N. Vinay Kumar — Reference 3 Engineering Portfolio

## Replace the images
All image paths are already wired into the React code. You only need to replace the files inside:

`public/images/`

Use these exact filenames:

### Profile
- `profile.jpg`

### ChurnGuard AI
- `churnguard-01.jpg` — main application/dashboard
- `churnguard-02.jpg` — prediction/risk result
- `churnguard-03.jpg` — analytics/history/database/API screen

### CivicCare AI
- `civiccare-01.jpg` — main application
- `civiccare-02.jpg` — complaint/risk analysis
- `civiccare-03.jpg` — map/urban-risk visualization

You can replace each placeholder with your own image while keeping the same filename. PNG/WebP is also fine, but if you change the extension you must update the corresponding filenames in `src/main.jsx`.

## Run
```bash
npm install
npm run dev
```
